# 名稱沒說出實際做的事
- 重點：計畫或 diff 新增或改名的函數、資料屬性，名稱只描述了它實際行為的一部分，或描述的是別的事。
- 怎麼抓：
  - 列出計畫或 diff 新增、改名的函數和資料屬性。
  - 每一個看輸入和輸出：它拿什麼、產出什麼、中間做了哪幾件事。
  - 名稱沒涵蓋其中會影響呼叫端的事（例如轉換了格式、排了序、寫了資料），算用錯。
  - 內容改了、名稱沒跟著改，改完後對不上，也算用錯。
  - 只看得到名稱、看不到內容時，標 ask。
- 例子：一個函數的名稱是「依代號分組」，實際除了分組，還把每一列編碼成給前端用的陣列。呼叫端從名稱看不出產出的是編碼後的格式。
